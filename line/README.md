# LINE公式アカウント — リッチメニュー / あいさつメッセージ

CoCosia の LINE 公式アカウント（`https://page.line.me/756assva`）に設定する内容一式。
**LINE Official Account Manager（管理画面）に手でコピペして設定する**前提でまとめている。

- 管理画面: https://manager.line.biz/
- 設定場所: 「ホーム」→ 左メニュー「トークルーム管理」→「リッチメニュー」/「あいさつメッセージ」

---

## 1. リッチメニュー

### 使う画像

`line/richmenu.png`（2500×1686px / PNG / 約145KB）

LINE の規定は「幅2500px・容量1MB以下・JPG/PNG」なので条件を満たしている。

### 管理画面での設定手順

1. 「リッチメニュー」→「作成」
2. **表示設定**
   - タイトル: `CoCosia メインメニュー`（管理用の名前。ユーザーには見えない）
   - 表示期間: 開始日のみ設定し、終了日は空欄（常時表示）
   - メニューバーのテキスト: `メニュー`
   - メニューのデフォルト表示: **表示する**
3. **コンテンツ設定**
   - テンプレートを選択 →「大」の **6分割（3列×2行）** を選ぶ
   - 「背景画像をアップロード」から `richmenu.png` を選択
   - 各エリア（A〜F）に下記のアクションを設定
4. 「保存」→ 「デフォルトに設定」

### 各エリアのアクション設定

画像の並びと同じ順（左上→右上→左下→右下）。

| エリア | 画像の表示 | アクション種別 | 設定値 |
| --- | --- | --- | --- |
| **A**（左上） | ご予約 / RESERVE | リンク | `https://tol-app.jp/s/vci08tspdhggsu8a0ooe` |
| **B**（中央上） | メニュー・料金 / MENU | リンク | `https://cocosia.relaxation-salon.workers.dev/#menu` |
| **C**（右上） | 初めての方へ / ABOUT | リンク | `https://cocosia.relaxation-salon.workers.dev/#about` |
| **D**（左下） | アクセス / ACCESS | リンク | `https://www.google.com/maps?cid=11824116614626448226` |
| **E**（中央下） | お電話 / TEL | リンク | `tel:08055239301` |
| **F**（右下） | Instagram / PHOTO | リンク | `https://www.instagram.com/cocosia.kitasenju` |

各エリアには「アクションラベル」も入力できる。音声読み上げ用なので、画像の表示と同じ文言
（`ご予約` `メニュー・料金` `初めての方へ` `アクセス` `お電話` `Instagram`）を入れておく。

> **エリアE（お電話）の注意**
> 管理画面のリンク欄が `tel:` を受け付けない場合がある。その場合は代わりに
> `https://cocosia.relaxation-salon.workers.dev/#info` を設定する（サイトの店舗情報セクションに
> タップで発信できる電話番号がある）。

### 画像を作り直すとき

`line/richmenu.html` がリッチメニュー画像のソース。文言や色を変えたらこのファイルを編集し、
以下のコマンドで PNG を再生成する（フォントは base64 で HTML に埋め込み済みなので追加DLは不要）。

```sh
cd line
/opt/pw-browsers/chromium-1194/chrome-linux/chrome \
  --headless=new --no-sandbox --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=2500,1686 --virtual-time-budget=5000 \
  --screenshot=richmenu.png file://$PWD/richmenu.html
```

色は HP（`index.html`）と同じ CSS 変数（`--cream` `--clay` `--earth` など）を使っている。
フォントも HP と同じ Noto Serif JP / Noto Sans JP / Cormorant Garamond。

## 2. あいさつメッセージ（友だち追加時に自動送信）

設定場所: 「トークルーム管理」→「あいさつメッセージ」

`{ユーザーのフレンド名}` は管理画面の「友だちの表示名」ボタンで挿入できる変数。
手打ちせず、必ずボタンから挿入すること。

### 採用案（標準・約340文字）

```
{ユーザーのフレンド名}さん
友だち追加ありがとうございます🌿

北千住駅 東口 徒歩3分のリラクゼーションサロン
CoCosia（ココシア）です。

▼ ご予約はこちら（24時間受付）
https://tol-app.jp/s/vci08tspdhggsu8a0ooe

「肩がずっと重い」「疲れが抜けない」など、
お悩みだけのご相談もこのトークで大歓迎です。
体の状態にあわせて、60〜180分の中から
メニューを組み合わせてご提案します。

当日・お急ぎのご予約はお電話が確実です。
📞 080-5523-9301
営業時間 12:00〜24:00（不定休）

下のメニューから、メニュー・料金や
アクセスもご覧いただけます。
```

### 予備案（短め・約150文字）

長文を嫌う場合はこちら。読了率は上がるが、初回相談のハードルを下げる文が消える。

```
{ユーザーのフレンド名}さん
友だち追加ありがとうございます🌿

北千住駅 東口 徒歩3分
リラクゼーションサロン CoCosia です。

▼ ご予約はこちら（24時間受付）
https://tol-app.jp/s/vci08tspdhggsu8a0ooe

ご相談だけでもお気軽にどうぞ。
当日のご予約は 📞 080-5523-9301 へ。
```

### 設定時のポイント

- あいさつメッセージは **1吹き出し500文字まで／最大5吹き出し**。上記はどちらも1吹き出しに収まる。
- 予約URLは必ず**単独の行**に置く。前後に文字があるとリンクとして認識されないことがある。
- 送信後、実機で友だち追加し直して**リンクが実際に開くか**を必ず確認する。

## 3. 設定後の確認チェックリスト

- [ ] リッチメニューが「デフォルトに設定」済みで、トーク画面を開いた時点で表示される
- [ ] A〜F の6エリアすべてがタップでき、意図した先に飛ぶ
- [ ] エリアA（ご予約）が TOL の予約フォームに到達する
- [ ] エリアE（お電話）が発信できる。できない場合は `#info` に差し替える
- [ ] あいさつメッセージが友だち追加直後に届く
- [ ] あいさつメッセージ内の予約URLがタップで開く
- [ ] `{ユーザーのフレンド名}` が実際の名前に置き換わっている
- [ ] 電話番号・営業時間・アクセスが HP（`index.html`）の表記と一致している
